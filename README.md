
# Aleksandria — Big Data & Connectionist AI

An educational project by **Team Aleksandria** exploring Big Data and Connectionist AI, with a focus on neural networks, data-driven learning, real-world applications, and ethical challenges.

## Project Overview

This project develops beginner-friendly learning resources explaining what Big Data is, how artificial neural networks learn, and how data and connectionist approaches are used together in AI systems.

## Target Learners

University students with little or no prior experience in AI.

## Learning Objectives

By the end of the materials, learners should be able to:

1. Define Big Data and describe its main characteristics.
2. Explain connectionism and the basic structure of an artificial neural network.
3. Describe how a neural network uses data during training to make predictions.
4. Identify practical applications and limitations, including data quality, bias, and privacy.

## Planned Content

1. **Introduction to Big Data** — Definitions, characteristics, examples, and data preparation.
2. **Connectionist AI** — Artificial neurons and the connectionist approach.
3. **Neural Networks** — Layers, weights, activation functions, and training.
4. **Big Data & AI** — How datasets support model development and evaluation.
5. **Applications & Ethics** — Examples, limitations, bias, and privacy.
