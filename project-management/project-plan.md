## 1. Project Overview

**Project:** Aleksandria — Big Data & Connectionist AI  
**Stage:** Stage 1 — Planning and Markdown V1.0  
**Repository:** https://github.com/Voryalis/aleksandria  
**Project coordinator:** Iatsenko Aleksandr — CEO / Project Coordination

**Target audience:** University students with little or no prior AI experience and high-school-level mathematics.

The project develops beginner-friendly educational materials explaining Big Data, connectionist AI, artificial neural networks, data-driven learning, applications, and ethical limitations.

## 2. Project Objectives

By the end of the learning materials, learners should be able to:

1. Define Big Data and explain its main characteristics, particularly volume, variety, and veracity.
2. Identify common data-quality problems and explain how preprocessing transforms raw data into usable model inputs.
3. Explain connectionism and describe the structure of an artificial neuron and a neural network.
4. Explain how inputs, weights, layers, and activation functions contribute to a model's prediction.
5. Describe how training uses prediction errors and loss to adjust a model's parameters, including a beginner-level explanation of backpropagation.
6. Explain how dataset quantity, quality, and representativeness affect model performance.
7. Discuss practical applications and limitations of AI, including bias, privacy, and reliability.

## 3. Scope and Chapter Structure

The five existing chapter files will be retained without restructuring.

| File | Chapter | Planned content |
|---|---|---|
| `docs/01-big-data.md` | Introduction to Big Data | Definition, volume, variety, veracity, data quality, preprocessing, and a labeled handwritten-digit example. |
| `docs/02-connectionist-ai.md` | Connectionist AI | Connectionism, artificial neurons, interconnected units, and learning from examples. |
| `docs/03-neural-networks.md` | Neural Networks | Inputs, weights, layers, activation functions, predictions, loss, training, and a beginner-level introduction to backpropagation. |
| `docs/04-integration.md` | Big Data and AI Integration | How raw datasets become model inputs; the relationship between data preparation, training, validation, and evaluation. |
| `docs/05-applications.md` | Applications and Ethical Considerations | Practical applications, dataset limitations, bias, privacy, and responsible use. |

### Shared example

Handwritten-digit recognition will be the common example across the chapters. It will connect data collection and labeling, image preprocessing, numerical inputs, neural-network predictions, training, and evaluation.
